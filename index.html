Code Example

Task: Count the number of distinct case-insensitive characters that occur more than once in a string.


            function duplicateCount(text) {
            const lower = text.toLowerCase();
            const counts = {};
            let duplicates = 0;

            for (let char of lower) {
                counts[char] = (counts[char] || 0) + 1;
            }

            for (let key in counts) {
                if (counts[key] > 1) duplicates++;
            }

            return duplicates;
            }
            
            Example: "aA11" → 2

Air Control Device

Device which was used for monitoring air quality in a specific area. It collects data on various air parameters such as temperature, humidity, and pollutant levels. The device is equipped with sensors that continuously measure these parameters and transmit the data to a central server for analysis and real-time monitoring. and next sents this data to mobile application, where users can view the air quality data in real-time, receive alerts about poor air quality, and access historical data for analysis. The project was developed using React Native for the mobile application, Python for the backend server, and MySQL for data storage. It also includes a real-time data monitoring system to ensure users have up-to-date information about their environment.
